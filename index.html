2. 실습 프롬프트 모음 · 복사해서 쓰세요

① PRD 생성 요청 — 기획실(채팅 프로젝트)에서
우리 부서는 관정별 수질 측정 엑셀을 분기마다 취합합니다. 측정값을 기준과 비교해 이상 여부를 확인하고 상태 요약을 붙여 보고합니다. 매번 수작업이라 시간이 오래 걸립니다.

이 업무를 자동화하는 도구의 PRD를 7항목 표준 템플릿으로 작성해줘.
② 화면 설계 — Claude Design에서
토양지하수처에서 쓸 '수질 측정 데이터 AI 분석 대시보드' 화면을 설계해줘.

- 상단: 판정 카드 4개 (전체/정상/주의/오염 의심)
- 중단: 관정별 TPH 시계열 차트 + 판정 분포 도넛
- 하단: 측정 데이터 표 (판정 뱃지, AI 해석 컬럼)
- 공공기관 남색 테마(#1A3A6B), 배경 #EEF2F7
- 엑셀 업로드 영역 포함
③ 이해 확인 — Claude Code(작업실)에서
폴더의 PRD.md와 design.html을 읽고, 무엇을 만들게 될지 3줄로 요약해줘.
④ 기능 구현 — Claude Code에서
폴더의 design.html과 PRD.md를 읽고, 동작하는 앱을 index.html로 만들어줘.

- SheetJS로 엑셀 업로드 → 표에 표시
- PRD 3번 판정 규칙대로 정상/주의/이상치/오염 의심 뱃지를 자동 표시
- Chart.js로 TPH 시계열(기준선 500) + 판정 도넛
- Claude API로 관정별 상태를 60자 요약 (키는 입력창으로, 없으면 규칙 문구로 폴백)
- 같은 폴더에 저장해줘
⑤ Supabase 연동 — Claude Code에서
분석 결과를 Supabase에 저장하고, 앱을 열 때 저장된 데이터를 불러와 표시하는 기능을 추가해줘.

- 테이블: water_quality (컬럼은 PRD 참고)
- Project URL과 anon key는 입력창으로 받기
- 'DB에 저장' / 'DB에서 불러오기' 버튼
- 저장 성공 시 건수 안내 메시지
⑥ 배포 플랜 B — GitHub이 막혔을 때
이 폴더를 Vercel로 배포해줘.
