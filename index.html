2. 실습 프롬프트 모음 · 순서대로 복사해서 쓰세요

① PRD 초안 받기 · Claude Code에서 (PRD_template.md · manual.html · 샘플 엑셀을 대화창에 드래그한 뒤)
우리 부서는 관정별 수질 엑셀을 분기마다 취합, 기준(먹는물 TPH 500)과 비교해 이상을 가려내고 상태 요약을 붙여 보고서로 냅니다. 이번에는 판정·요약 대시보드까지만 자동화합니다.

매뉴얼의 기준과 컬럼대로, 첨부한 템플릿 양식으로 PRD.md 문서로 초안을 작성해줘. 부족한 정보는 먼저 질문해줘.
② 화면 설계 · 쓰던 대화에서 그대로 (/design 포함 전체 복사)
/design 토양지하수처에서 쓸 '수질 측정 데이터 AI 분석 대시보드' 화면을 설계해줘.

- 상단: 판정 카드 4개 (전체/정상/주의/오염 의심)
- 중단: 관정별 TPH 시계열 차트 + 판정 분포 도넛
- 하단: 측정 데이터 표 (판정 뱃지, AI 해석 컬럼)
- 공공기관 남색 테마(#1A3A6B), 배경 #EEF2F7
- 엑셀 업로드 영역 포함
③ 시안 저장 · 마음에 드는 시안을 고른 뒤
이 시안을 design.html로 저장해줘.
④ STEP 1 · 화면 골격
폴더의 design.html과 PRD.md를 읽고, 화면 골격만 있는 step1.html을 만들어줘.

- 시안의 레이아웃 그대로: 카드 4 · 차트 2 자리 · 데이터 표 · 엑셀 업로드 영역
- 데이터는 더미 3건을 하드코딩해서 표에 표시
- 차트는 자리만 잡아둬 (다음 단계에서 그린다)
- 엑셀 파싱·AI·DB 기능은 아직 넣지 마 (STEP 2~4에서 하나씩 붙인다)
- 같은 폴더에 저장해줘
⑤ STEP 2 · 판정과 차트
step1.html과 PRD.md를 읽고, 기능이 동작하는 step2.html을 만들어줘.

- SheetJS로 엑셀 업로드 → 표에 표시
- PRD 3번 판정 규칙대로 정상/주의/이상치/오염 의심 뱃지를 자동 표시
- Chart.js로 TPH 시계열(기준선 500) + 판정 도넛
- AI 해석과 Supabase는 다음 단계에서 하니 지금은 넣지 마
- 같은 폴더에 저장해줘
⑥ STEP 3 · AI 해석
step2.html과 PRD.md를 읽고, AI 해석이 붙은 step3.html을 만들어줘.

. Claude API로 관정별 상태를 60자 요약
  (키와 워크스페이스 ID는 입력창으로 받고, 키가 없으면 규칙 문구로 폴백)
. '종합 리포트 생성' 버튼: 판정 집계를 행정 어조 보고서로 작성, 복사 버튼 포함
. 판정은 PRD 3번 규칙 그대로 (AI가 못 바꿈)
. Supabase는 다음 단계에서 하니 지금은 넣지 마
. 같은 폴더에 저장해줘
⑦ STEP 4 · Supabase 저장
step3.html과 PRD.md를 읽고, 분석 결과를 Supabase에 저장하고 불러오는 step4.html을 만들어줘.

- 테이블: water_quality (컬럼은 PRD 참고)
- Project URL과 Publishable(anon) key는 입력창으로
- 'DB에 저장' / 'DB에서 불러오기' 버튼
- 저장 성공 시 건수 안내 메시지
- water_quality 테이블 컬럼은 소문자 9개야: well_id, measure_date, ec_uscm, do_mgl, orp_mv, ph, tph_ugl, judgment, ai_summary. 저장할 때 엑셀 컬럼을 이 이름으로 변환해서 이 9개만 보내줘 (GWL_m은 저장 안 함)
- 같은 폴더에 저장해줘
⑧ 응급 SQL · 저장이 "row-level security"로 막힐 때 (Supabase → SQL Editor에서 Run)
alter table water_quality disable row level security;
⑨ 배포 · 최신 단계를 첫 화면으로
step4.html을 index.html로 복사해줘. GitHub에 올릴 준비를 하려고 해.
⑩ Day 2 · 우리 조 테이블 설계 (조별 과제)
우리 조 화면 파일과 PRD.md를 읽고, 이 화면에 표시되는 데이터를 저장할 테이블을 설계해줘. 어떤 단위로 쌓을지부터 정하고, 컬럼명은 영문 소문자로, 타입까지 표로 제안해줘.
